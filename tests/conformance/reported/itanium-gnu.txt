# Itanium C++ names that each exposed a distinct defect, read in the gnu style.
#
# One row per name: the mangled name, a tab, the expected spelling in the gnu style.
# There is no count to update; CONTRIBUTING.md has the format.
#
# GNU c++filt hands a PE import thunk back unchanged, and a style decides spelling, not
# whether a name reads: these keep the llvm style's `import thunk for ` and spell the
# name inside it as c++filt spells that name alone.
#
# reference: GNU c++filt (GNU Binutils for Ubuntu) 2.42, for the name after `__imp_`
# (with `-_` for a `__Z` one).
__imp__Z3foov	import thunk for foo()
__imp___Z3foov	import thunk for foo()
__imp__ZN2ns3barIiEEvT_	import thunk for void ns::bar<int>(int)
__imp__ZNSt6vectorIiSaIiEE9push_backERKi	import thunk for std::vector<int, std::allocator<int> >::push_back(int const&)
